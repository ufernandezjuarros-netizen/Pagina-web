Termino Nagusiak (Klikagarriak)

Phishinga

Iruzurrezko teknika bat da, non erasotzailea erakunde fidagarri baten moduan aurkezten den (adibidez, banku bat edo posta zerbitzu bat) biktimaren informazio konfidentziala lortzeko, hala nola pasahitzak edo kreditu-txartelen datuak.

Biren Erasoa (Man-in-the-Middle)

Erasotzailea bi alderdiren arteko komunikazioan ezkutuan sartzen denean gertatzen da, elkarrizketa edo datu-trukea ikuskatzeko edo aldatzeko, biek zuzenean elkarrekin hitz egiten ari direla uste duten bitartean.

Troiarra (Trojan)

Nahi den edo erabilgarria den software baten itxura duen programa kaltegarria (malwarea) da, baina exekutatzerakoan erasotzaileari sistemarako sarbide ez baimendua ematen diona.

Backdoorsak (Atzeko Ateak)

Sistema edo programa batean nahita edo malware bidez utzitako sarbide sekretu bat da, ohiko autentifikazio prozesuak saihestuz sisteman sartzeko aukera ematen duena.

Spywarea

Erabiltzailearen baimenik gabe bere gailuko jarduera jarraitzeko, datuak biltzeko eta informazio hori hirugarrenei bidaltzeko diseinatutako software software kaltegarria.

Stealerrak (Informazio Lapurrak)

Gailutik informazio zehatza lapurtzera bideratutako spyware mota espezifikoa da; esaterako, nabigatzailean gordetako pasahitzak, saio-hasierako tokenak edo kriptomoneta-zorroen datuak.
